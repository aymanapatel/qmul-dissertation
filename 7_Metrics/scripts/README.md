# Report metric figures

Run from the repository root:

```bash
python3 7_Metrics/scripts/generate_report_graphs.py
```

Generate the learning-v2 training-dynamics figure separately:

```bash
python3 7_Metrics/scripts/plot_learning_v2_training.py
```

The script reads the frozen JSON artefacts under
`3_Learning/learning_v2/artifacts_evidence-v3.0` and writes 300-DPI PNG and
vector PDF versions to `7_Metrics/scripts/images`.

## Figures

- `final_detection_f1_ci`: final site--criterion F1 with 95% site-bootstrap
  confidence intervals (101 sites and 404 decisions).
- `final_precision_recall_tradeoff`: final operating points; marker area
  represents criterion coverage.
- `final_per_criterion_f1`: axe-core and learned-specialist F1 for the four
  independently adjudicated criteria.
- `accessibility_tree_specialist_f1`: node, rule, and page F1 on the held-out
  development-label protocol.
- `learning_v2_training_dynamics` (generated by
  `plot_learning_v2_training.py`): exact sampled BCE training loss and
  deterministic, training-matched sampled validation loss for the rerun of the
  final accessibility-tree GraphSAGE configuration. The lower panel shows the
  validation rule-macro average precision used for checkpoint selection. A CSV
  records both plotted series and the full valid-pair validation BCE.
- `visual_ablation_f1`: colour-contrast F1 mean and standard deviation across
  seeds 41, 42, and 43.
- `retrieval_benchmark`: recall, source correctness, and record diversity for
  the six-query controlled retrieval benchmark.

For LaTeX, prefer the vector PDF version:

```latex
\begin{figure*}[t]
  \centering
  \includegraphics[width=0.94\textwidth]{../7_Metrics/scripts/images/final_detection_f1_ci.pdf}
  \caption{Final site--criterion F1 against independently adjudicated manual truth. Error bars show 95\% site-bootstrap confidence intervals.}
  \label{fig:final-detection-f1}
\end{figure*}
```

The visual-specialist point has only 0.25 criterion coverage and must not be
described as a four-criterion system result. The accessibility-tree figure uses
axe-derived development labels, whereas the figures prefixed `final_` use the
independently adjudicated final test.

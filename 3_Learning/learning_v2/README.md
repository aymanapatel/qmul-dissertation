# Learning implementations

The learning code is organised by implementation version:

- `learning_v1/` contains the original DOM/accessibility-tree/rendered-visual GNN implementation, its scripts, tests, plans and launcher.
- `learning_v2/` contains the governed specialist-model training, calibration, routing and evaluation implementation.
- `accessibility_system/` contains the downstream retrieval and remediation system.

Run version-specific commands from the corresponding version directory. Generated reports and run artifacts remain at the `3_Learning/` level so historical results retain their existing paths.
